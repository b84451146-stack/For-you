# Rose bouquet in ASCII

A 3D bouquet of 19 roses made of text characters. It grows, blooms, and types out a message. Runs in any browser, no install needed.

## Put it online with GitHub Pages
1. Upload these files to a new GitHub repo.
2. Go to Settings > Pages, set the source to the main branch, root folder, and save.
3. Your link will be https://YOUR-USERNAME.github.io/REPO-NAME/

## Change the message
Open `index.html` and edit the line starting with `var MESSAGE=`.
